# getStanley

Landing oferty getStanley: zespoły botów-pracowników AI.

Live: https://stanleyagent.github.io/

## Languages (i18n)

- `/` redirects to `/pl/` (Polish is the canonical/default locale)
- `/pl/` — Polish
- `/en/` — English

To add a language (e.g. German): create `/de/index.html`, add `{ code: "de", label: "Deutsch", path: "/de/" }` to the `LOCALES` array in both existing locale pages (search `// LOCALES`), and add a matching `hreflang` alternate link.
